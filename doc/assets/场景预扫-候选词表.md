## 二、更要紧的一件事:NGSL 词频 ≠ 学习难度

预扫顺带暴露了一个比缺词严重的问题。看这些**已经在词表里**的词的 band:

| 词 | band | 意味着 |
|----|------|--------|
| `hello` | **2811** | L1–L5 全部算越级 |
| `apple` / `milk` / `station` / `shoes` | 950 | L1 用不了 |
| `bread` / `tea` | 1000 | L1 用不了 |
| `bag` | 600 | L1 用不了 |
| `fine` | 657 | L1 用不了 |
| `red` | 700 | L1 用不了 |
| `open` | 520 | L1 用不了(差 20) |
| `rice` | 2800 | L1–L4 全用不了 |

band 取自 NGSL 的**通用语料词频 rank**。`hello` 在新闻与学术语料里罕见,
所以 rank 2811 —— 但对初学者它是第一个学的词。

实测本级留存率(L1,每场景 10 句):

| 场景 | 本级入库 | 被改级推走 |
|------|---------|-----------|
| 问候与寒暄 | 9 | 1 |
| 课堂用语 | 8 | 2 |
| **超市购物** | **3** | **6** |

具体名词多的 L1 场景,七成产出会被推到 L2/L3。按现状跑 5000 句,
**L1 会严重欠产**,而且欠得看不出来(生成"成功"了,只是句子都去了上一级)。

### 三个选项

**(a) 接受现状。** L1/L2 以功能词和句型为主,具体名词自然落在 L3+。
改动为零,但 L1 的场景清单要缩,`targets` 里 L1 的 700 句要下调。

**(b) 加一层教学定级覆盖表(推荐)。** 现在词表分两层:
`base.tsv` = NGSL(可核对)、`supplement.tsv` = NGSL 没有的词。
缺的是第三层 —— **我们明确不同意 NGSL 的地方**:

```
content/lexicon/overrides.tsv
lemma    band    理由
hello    30      初学第一个词;NGSL 2811 反映的是书面语稀有度
milk     380     A1 具体名词
red      300     基础颜色词
```

三层各自可审、互不污染:NGSL 说什么 / NGSL 缺什么 / 我们哪里不同意且为什么。
`sf gold run` 加一条:overrides 里的词必须在 base 里(不在的话它属于 supplement)。
搭架子我来做,词由你审 —— 大概 100–200 个 A1/A2 高频具体名词。

**(c) 直接调高各级 vocab_band。** 最省事,但会连带影响**定级测试**
(它按 band 分层抽样出题),等于把整套难度标尺往上推。不建议。
