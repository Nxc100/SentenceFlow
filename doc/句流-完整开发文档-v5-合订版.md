## 1. 产品定位与商业形态

### 1.1 一句话定位

一款**买断制**的英语整句输出训练软件:看中文、打英文,答对瞬间自动展开"音标 + 词性 + 句子成分"的可视化解析;内置六级、五千句日常交流句库,完全离线可用;接入本机 opencode(免费模型)或你自己的 API Key 后,还能为任何场景现场生成带全套解析的专属练习。

### 1.2 目标用户

| 角色 | 描述 | 核心诉求 | 付费动机 |
|---|---|---|---|
| 成人自学者(核心) | 重学英语的上班族、程序员、出国准备者 | 低压力可量化的每日输出练习;数据本地;一次付费永久使用 | 买断 + 自定义场景生成("下周出差要用的机场句子");极客人群天然会装 opencode,零费用解锁 AI 功能 |
| 学生(核心) | 小学高年级–初中 | 开箱即练,不注册不联网也能学 | 家长购买;AI 通道对学生完全可选 |
| 家长(付费决策者) | 关注有效性与屏幕安全 | 无广告无内购诱导;看得见的本地报告 | 买断的确定性(无订阅焦虑) |

### 1.3 商业模式

- **定价形态**:个人永久授权买断;跨大版本升级另购升级价(Sublime Text 模式)。价位为开放问题(§10),参考区间 ¥99–149。
- **销售渠道(无自有服务器)**:海外 Paddle / Lemon Squeezy(商户记录模式:代收款、代缴税、托管下载、可自动发许可证,以其当日文档为准);国内爱发电/面包多发卡。
- **授权技术**:离线许可证,Ed25519 本地签发、客户端内嵌公钥验签,不依赖激活服务器;**不绑定设备**(离线制无法真正跨设备计数,与其做半吊子指纹徒增换机摩擦,不如 honor system + 条款约束)。
- **试用**:桌面端 14 天全功能;Web 试用版永久免费承担导流(§7.9)。
- **防盗版哲学**:纯客户端授权必然可破解;工程投入全部花在让正版用户方便——激活十秒、换机零摩擦、许可证可自行备份。

### 1.4 五条设计立场(不可谈判项)

1. **心流优先**:练习页是无菌区——无红点、无弹窗、无促销、无激励元素;一屏只做一件事。
2. **彩色即语义**:界面本体近乎无彩(蓝 + 灰),粉彩色板**只**用于词性与句子成分;颜色是教学信息,不是装饰。
3. **反成瘾**:不做无限流、不做抽卡、不做付费催促;每日达标主动提示休息。
4. **本地即隐私**:学习数据只存本机;Key 存系统钥匙串;**不读取用户的 opencode 凭据**;用户运行时数据永不经免费端点之外还要在界面上可见(§5.5 本地徽标)。
5. **花钱必透明**:消耗用户 Key 或免费额度的操作,调用前预估、调用中实时计量、触顶硬拦截,永不静默烧钱(§5.5 CostBar)。

### 1.5 无遥测取舍声明

无服务器 = 无埋点。产品内统计仅服务于用户自己的报告页;迭代依据:发卡平台的试用→付费转化数据、GitHub Discussions / 用户群定性反馈、用户**主动**导出的匿名诊断包。这是隐私立场的代价,接受它。

## 3. AI 引擎:四通道架构与 opencode 可行性判定

### 3.1 核心判定(已经官方文档核实)

opencode 官方提供两条被外部程序驱动的路径:

1. **`opencode run`(非交互)**:prompt 作参数、流式输出 stdout、空闲即退;支持 `--model provider/model`、`--format json`、stdin 管道、`--attach <server-url>`。
2. **`opencode serve`(无头服务)**:本机 HTTP 服务(默认 127.0.0.1 随机端口,可 `--port` 固定),OpenAPI 说明位于 `/doc`,官方 `@opencode-ai/sdk`;会话式:`session.create → session.prompt`;`OPENCODE_SERVER_PASSWORD` 启用 basic auth。
3. 凭据由 opencode 自管(`opencode auth login` → `~/.local/share/opencode/auth.json`);`opencode models` 枚举可用模型。

结论:**把本机 opencode 当作"本地推理运行时"是官方支持的用法**。我们发布的是跑在它之上的专用生成 Agent 配置 + Rust 调用编排——harness 工程在客户端的形态。

### 3.2 三个假设修正

| 原设想 | 事实 | 产品应对 |
|---|---|---|
| 装了 opencode 就能免费用 | 装了 **+ 登录 Zen** 才有免费模型;免费 ≠ 免登录 | 通道卡三态引导(§5.5 / §6.3) |
| 免费模型稳定存在 | 限时活动、名单轮换、有限速;个别模型(如 Big Pickle)免费期数据可能用于训练 | 微基准择优(§3.5)、按模型标注条款、channels.json 远程降级(§3.6) |
| 可做唯一引擎 | 是四通道之一;Web 试用版无法拉起本地进程 | 出厂库保证零配置可练;三条通道互为兜底 |

### 3.3 四通道总表

| 通道 | 形态 | 费用 | 前提 | 定位 |
|---|---|---|---|---|
| **opencode 本地** | 驱动本机 CLI(serve 首选 / run 降级) | 0(免费额度内,限速) | 已装 + 已登录 | 极客零费用通道;开发侧工厂 T1 主力 |
| DeepSeek 官方 | HTTPS API | 按量(前缀缓存 + 错峰) | 用户 Key | 质量与稳定基准;修补/答疑首选 |
| Zen 直连 | OpenAI 兼容 API(`opencode/<model-id>`) | 免费模型 0 / 付费按量 | Zen Key | 不装 CLI 也想用免费模型的折中 |
| Ollama 本地 | localhost:11434 | 0 | 本机已装 | 全离线兜底 |

### 3.4 适配器抽象与 opencode 双模式

```rust
// crates/sf-llm —— 四通道同一 trait,上层无感知
#[async_trait]
pub trait ChannelAdapter: Send + Sync {
    async fn probe(&self) -> ChannelStatus;   // NotInstalled | NotAuthed | Ready{models} | Error
    async fn complete_stream(&self, req: GenRequest)
        -> Result<BoxStream<GenChunk>, ChannelError>;
    fn meter(&self) -> MeterKind;             // Money{prices} | RateBudget{rpm_est}
}
```

opencode 适配器:**serve 模式**(首选)——自拉专属实例 `opencode serve --port 0`(读 stdout 得端口)+ 随机 `OPENCODE_SERVER_PASSWORD` 防本机搭车,cwd = 沙箱目录,空闲 5 分钟自动退出;**run 模式**(降级)——逐次 `opencode run -m opencode/<model> --format json`,prompt 走 stdin。版本探测 `--version` 对照基线与 known-bad 名单;**隐私红线:绝不读取 auth.json**,登录态只经 `opencode models` 输出间接判定。

**Agent 三重约束**(opencode 是带工具的 agent,而我们只要"文本进、JSON 出"):① 空沙箱 cwd(`~/.sentenceflow/agent-sandbox/`,即使工具失控也无可写目标);② 沙箱内我方托管的 `opencode.json` 定义 `sf-gen` 专用 agent——锁系统提示、指定模型、权限全 deny(禁文件/命令/网络工具;键名以官方当日文档为准,W2 spike 钉死);③ 输出即契约——一切产物必须过 sf-pipeline 确定性校验才能入库,前两层失效也不产出破碎数据。

**自律条款**(ToS 灰区应对):经用户本机 opencode、以用户自己的账号与额度请求;不伪装来源、不绕限速、限速即退避;Zen 条款在通道卡明示;若官方明确反对,channels.json 一键停用——产品因出厂句库不依赖它存活。

### 3.5 免费模型择优:能力微基准

免费名单(如 Nemotron 3.5 Lightning / DeepSeek V4 Flash / Laguna S 2.1 / Hy3 / MiMo V2.5 / Big Pickle 等,以实时列表为准)会轮换,且各家**结构化输出纪律差异大**。通道就绪后首次使用:每个候选模型生成 6 句 → 本地校验器打分(JSON 合格率、越级率、时延)→ 生成工坊默认选最高分,其余按分排序;结果连同名单指纹存 progress.db,**名单变化自动重测**。每模型 1 次请求的前置投资,换后续全部请求的成品率。

### 3.6 channels.json:无服务器的远程开关

随内容包 rev 分发的通道策略文件:各通道启用位、opencode known-bad 版本、免费名单指纹、DeepSeek 价格表、默认微批大小。免费政策突变、CLI 破坏性更新、需下线某通道时,**发一个内容包即可,应用本体不发版**——这是无服务器架构下唯一的"遥控器"。

## 4. 功能规格

### 4.1 练习引擎(P0)

| 规则 | 规格 |
|---|---|
| 打字模式 | 上方中文;下方按单词划分的下划线格,长度与字母数成正比;句末标点直显不输入;大小写不敏感(回显用户所打);仅收 a–z/A–Z |
| 严格模式(默认) | 错字**不上屏**:当前格 ±5px 抖动 240ms + 红色字母原位闪现 200ms 淡出;错误计数 +1 |
| 宽松模式 | 错字上屏标红,Enter 整句校验,错误词清空重打 |
| 自动跳格与防双跳 | 词满自动跳下一未完成词;**当前词为空时空格无动作**(防"自动跳格 + 顺手空格"双跳);词内有输入时空格 = 跳词;全满时空格 = 提交 |
| 完成判定 | 全部正确即自动提交进解析,无需 Enter |
| 显示答案 | ↓ 浅灰揭示(记"看过答案",不计连对);↑ 收起 |
| 拆句重组 | 词块乱序点击拼句,点错抖动;支持重复词;定位为低龄/键盘不熟入口,可设"先重组后打字"两遍流 |
| 听打(P0) | 不显中英,自动播 1 遍;Ctrl 重听(≥3 次记听力薄弱信号);长按 0.75× 慢速;piper 离线 TTS |
| 默写(P0) | 只显中文,自由输入整句,Enter 逐词 diff:对绿、错红删除线附正确词、漏词灰占位;仅对盒 ≥3 句开放 |
| 移出范围 | 跟读评分(依赖云评测 SDK,与无服务器冲突) |

验收:60 WPM 连打 20 句无丢字;中文输入法激活态无副作用(拦 composition);断网练习零降级。

### 4.2 句子解析系统(P0)

三层信息:词层(音标 + 词性胶囊)→ 块层(成分彩色卡片)→ 句层(点"句子解析"展开句型公式 + 讲解)。点词朗读;←→ 词间移动并朗读;Ctrl 整句。**AI 答疑**(通道就绪后):解析视图右下"问 AI"→ 底部抽屉就本句提问,流式回答;无通道时入口不出现(不做灰化诱导)。

### 4.3 内容体系(P0)

出厂句库(≈5000 句,content.db 只读内置)· 我的句集(生成工坊产物 + "中文 Tab 英文"双列导入,存 user_content.db,与出厂库同 schema 物理隔离)· 错题本(错 ≥2 次或标"不熟悉"自动收录,一键重练)· 收藏 · 内容更新(修错/扩充随内容包 rev 免费分发,用户句库永不被触碰)。

### 4.4 生成工坊(P0,AI 扩展的招牌)

**入口态**:无通道 → 引导卡(四通道对比 + "去接入" + 一行小字"不接入也不影响任何学习功能");就绪 → 工作台。**场景生成流**:场景描述(自由文本)+ 等级(默认当前)+ 句数(10/20/30)→ CostBar 预估 → 生成:句卡流式落下,实时校验角标(✓/⟳/✕ 可展开原因)→ 摘要"24 通过 · 3 修补 · 3 丢弃" → 勾选入库,可立即开练。**定向加练**:报告页薄弱项(如"介词错误率 38%")一键预填参数进同一流程。**周点评**:本周聚合数字(不含逐句内容)发所配模型,200 字点评 + 三条建议,存本地。**质量兜底**:每卡 [重新生成] [报错];丢弃句折叠可捞回——用户的额度用户做主。

### 4.5 SRS 与报告(P0)

Leitner 五盒:盒 1 当天 → 盒 2(1 天)→ 盒 3(3 天,解锁默写)→ 盒 4(7 天)→ 盒 5(15 天抽检);答错或 Ctrl+Q 回盒 1,Ctrl+M 直入盒 5;听打答对按 1.5× 权重推进。每日队列 = 到期复习优先(上限 60)+ 新句补足(默认按等级,5–50 可设);复习句混排仅以小圆点弱提示。掌握口径:盒 ≥4。报告:今日卡、热力日历、WPM/正确率曲线、按词性与成分的薄弱分析(每项带结论一句话 + [AI 加练]);**周报 PDF 一键导出**(A4 一页,家长看文件——替代已作废的云推送)。

### 4.6 授权与激活(P0)

试用 14 天全功能(起点写文件 + 钥匙串双份;检测时钟回拨即到期,不做更深对抗);激活 = 粘贴/拖入 `.sflic` → 本地 Ed25519 验签;到期后为体验模式(每日 5 句,不清数据、不弹窗,顶栏胶囊常驻购买入口)。许可证格式与签发见 §7.6。

### 4.8 设置与无障碍(P0)

## 5. UI 设计规范

### 5.1 设计原则(六条)

1. **一屏一事**:练习页顶底栏静止 3s 后淡至 40% 透明,任何输入即恢复。
2. **彩色即语义**:粉彩色板为词性/成分专属,禁止用于按钮、插画、任何运营位。
3. **圆与软**:大圆角、无锐角、无 1px 硬分割线(留白与底色分区);Nunito 的圆润字形是该原则在字体上的延伸。
4. **反馈即时且可跳过**:任何操作 100ms 内有视觉响应;庆祝动画可被按键立即打断。
5. **签名时刻只有一个**:"答对 → 格线消融 → 单词聚拢成彩色成分卡片"是全产品唯一允许铺张的动效(§6.2),撒花为其专属。
6. **钱与隐私的视觉在场**:CostBar 与本地徽标是常设组件,不藏进二级页。

## 6. 交互与动效规范

### 6.1 动效 Token

`dur-instant 80` / `dur-fast 140` / `dur-base 220` / `dur-slow 320` / `dur-celebrate 1200`;`ease-standard cubic-bezier(.2,0,0,1)` / `ease-out (0,0,0,1)` / `ease-spring (.34,1.56,.64,1)`。约束:位移 ≤16px、缩放 ≤1.08、同屏运动 ≤3 组(签名时刻除外)、一切可被输入打断;`prefers-reduced-motion` 或设置"减少动效"→ 全局降级为 120ms 淡变、禁撒花。

### 6.2 打字微交互与签名时刻(产品灵魂)

**微交互逐项**:落字 scale 0.6→1.08→1(140ms ease-spring);错字当前格 ±5px 抖动 240ms + 红字原位闪现 200ms 淡出;跳格时蓝色下划线 120ms 滑移(非瞬移);退格字母缩小淡出 100ms;当前格 1.6s 呼吸,90s 无输入呼吸加深 + 淡入"按 Ctrl 听听发音?";重组词块 FLIP 飞入 220ms 落点回弹,点错原地抖动。

**签名时刻(t0 = 末字落定,总 1.4s,任意按键跳终态)**:

| 时间 | 效果 |
|---|---|
| t0 | 全部下划线 160ms 淡出,字母颜色加深 |
| t0+160 | FLIP:单词按成分聚拢,成分卡片底色 0→100%(320ms),自下 8px 上浮 |
| t0+300 | 词性胶囊逐词 stagger 40ms 自下弹入(ease-spring) |
| t0+380 | 音标行淡入 |
| t0+420 | 撒花 1.2s(60–90 粒,取语法色板底色系)+ 正确音"叮"(880Hz,90ms,−14dB) |
| t0+500 | 本地 TTS 朗读整句 |
| t0+700 | 中文与"句子解析"按钮淡入,快捷键条切换 |

撒花是**练习答对的专属仪式**——激活成功、生成完成等一切其他场景禁用。

### 6.3 关键交互流

**首启(≤60 秒,零配置)**:六张等级卡(各一个 can-do 例句)或"帮我测一下"(自适应 3 句定级)→ 直接进该级第一节 → 30 秒内体验签名时刻 → 首节完成页以一张安静卡片介绍生成工坊("可选功能,接入 AI 通道后启用")。**通道配置绝不出现在首启路径。**

**通道配置流**:AI 接入页选卡。opencode 卡按三态引导:未安装 → 复制安装命令,装完 [重新检测];未登录 → 复制 `opencode auth login`,登完 [重新检测];就绪 → 首次使用触发微基准(骨架卡 + "正在为你挑选最合适的免费模型,约 30 秒,仅一次")。Key 类通道:输 Key → [测试连接](≤3s 转圈)→ 绿勾 toast"已连通,生成工坊可用" / 红叉 + 人话释义 + 动作链接。

**生成流**:点击[生成]→ CostBar 进入计量态 → 骨架卡 → 句卡逐张流入(自下 8px 上浮 + 淡入,stagger 40ms),每卡英文/中文两段流式填充;校验角标 ⟳→✓ 时词性标签以 mini 签名时刻展开(200ms,**无撒花**);⟳→✕ 降 60% 透明折叠至"已丢弃"区。队列微批以进度点呈现;[停止] 即刻停表且保留已产出;完成 → 摘要滑入 + 入库按钮。

**预算与限速**:付费通道触顶 → 模态:"已达单次预算 ¥1.00 · 已完成 18/30 句",主按钮[入库已完成](默认焦点),次[提高上限继续],幽灵[放弃]——保守选项永远最顺手。免费通道 429 → 不报错,骨架卡内"免费额度限速,8s 后自动继续"倒计时(指数退避上限 60s);连续 3 次 → 顶部细条建议切换通道。断点续跑:中断任务在队列区显示 [续跑],已过校验句先行入库。

**激活流**:粘贴/拖入许可证 → 本地验签(<50ms)→ 授权卡由虚线翻转实底,右上绿印章 scale 1.3→1 + 8° 回正盖下(220ms ease-spring)+ 上行双音——庄重不抢戏,无撒花。失败:卡片抖动 240ms + 具体原因("签名无效:请确认复制完整")。

**试用与体验模式**:顶栏胶囊"试用 · 剩 n 天"(≤3 天转 warning);到期次日首启一张可直接关闭的全屏说明页(非弹窗),此后仅胶囊常驻"体验模式 · 每日 5 句 · 购买完整版"。**永不弹购买窗。**

**AI 答疑**:解析视图"问 AI"→ 底部抽屉(高 40%)预填模板("为什么这里用 __?"),回答打字机流式(60 字/s),不遮句子本体。

### 7.3 sf-core(纯函数,双端逐比特一致)

```rust
pub fn build_session(all_due: &[(SentenceId, SrsState)], new_pool: &[SentenceId],
                     spec: &LevelSpec, now: i64, rng_seed: u64) -> Session;
pub fn apply_outcome(s: SrsState, o: Outcome, mode: Mode, spec: &LevelSpec, now: i64) -> SrsState;
pub fn judge(input: &str, target_words: &[&str], policy: &JudgePolicy) -> Verdict; // 逐词 diff
pub fn fold_stats(logs: impl Iterator<Item = LogRow>) -> StatsSummary;
```

桌面以 Tauri command 薄封装(rusqlite 取数后调 core);试用版经 sf-wasm 同名导出。存储不进 core。

### 7.4 sf-pipeline:统一管线,双档位

```
GenRequest(LevelSpec + 场景/功能 + 批参数)
 → prompt 装配(稳定前缀:Spec 原文 + schema + few-shot;变量尾:任务 + simhash 指纹)
 → ChannelAdapter 流式生成(LLM 一次出齐 en/zh/words/chunks/note)
 → 增量解析 → 确定性校验(0 token):NGSL fst 越级 · 句长 · chunks 全覆盖不重叠
   · POS 枚举 · IPA 字符集 · simhash 查重 · lemma 词典对账覆写(音标漂移归零)
 → 分诊:标注失败 → 修补调用(仅传差异);越级 → 改级(factory)/标丢弃可捞回(user)
 → 入库(content.db / user_content.db)
```

| 档位 | factory(`sf factory build`) | user(生成工坊) |
|---|---|---|
| 通道 | opencode 本地 T1 → DeepSeek 错峰 T2/T3 | 用户所选通道 |
| 校验 | 严格:越级改级、白名单全查、5% 人工抽审 | 宽松:表面规则、越级即弃可捞回 |
| 质量闭环 | 金标 200 回归、prompt 版本化、失败样本回灌 few-shot | [重新生成] + 报错通道 |

spaCy 退出主环(免费通道使省 token 理由消失),保留为 `tools/audit` 离线审计;dsh 移出依赖树(设计思想保留)。开发侧 5000 句:免费通道微批(20 句/请求,约 350 次)一至两天;DeepSeek 错峰兜底 ≈ ¥8–12。

### 7.5 sf-llm:四通道、计量双轨、护栏

trait 与 opencode 双模式见 §3.4。计量:`Money`(tiktoken-rs 预估 + usage 回填 + prices 表 + 单次预算硬顶,流中触顶优雅收尾)/ `RateBudget`(客户端令牌桶 + 请求计数 + 指数退避可视)。任务队列 `gen_queue` 持久化(微批、断点续跑、半成品先入库)。Key 经 `keyring` 入系统钥匙串,内存 `SecretString`,日志脱敏。**练习路径零网络调用**——sf-core 与练习 UI 不链接 sf-llm,架构上可审计。所有请求仅出自生成工坊/答疑/周点评三入口。

### 7.6 sf-license:离线授权

```json
{ "v": 1, "product": "sentenceflow", "edition": "personal",
  "email": "user@example.com", "major_max": 3,
  "issued_at": 1765900800, "sig": "base64(ed25519(payload))" }
```

客户端内嵌公钥验签(`ed25519-dalek`);`major_max` 承载"买断 + 大版本升级付费";不绑设备。签发 CLI:`sf-license issue --email x@y.com --major-max 3`,私钥存离线 U 盘 + 密码管理器,绝不入仓库;爱发电订单 → 脚本签发 → 邮件模板(每单 <10 秒);Lemon Squeezy 内置许可证功能可作自动发货平行通道(以其当日文档为准)。试用:首启时间戳文件 + 钥匙串双份,`now < last_seen` 判回拨即到期。

### 7.7 数据层

- `content.db`(出厂只读):`meta(rev/spec_hash…)`、`sentence(id, level, scene, func, pattern, zh, en, punct, words JSON, chunks JSON, note_tpl, note_slots, simhash, license, attribution, rev)`、`lemma(lemma, ipa_gb, ipa_us, zh_gloss, band, audio)`(≈3000 词条,兼作客户端本地词典)、`note_tpl`、`level_spec`(YAML 快照,内容与行为同版)。体积:5000 句 ≈3.5MB(gzip ≈1MB);词级音频包 ≈24MB 桌面内置。
- `user_content.db`:同 schema,`meta.origin='user'`;练习引擎经统一 ContentIndex 读两库并集,对来源无感知。
- `progress.db`:`srs(sentence_id, box, due_at, err, last_mode, last_at, seen_answer)`、`log(ts, sentence_id, mode, result, dur_ms, errors, wpm)`、`kv`、`spend(ts, provider, tokens_in, tokens_out, cost_est, requests)`、`gen_queue(job_id, params, state, produced, ts)`、`bench(model, score, latency, list_fingerprint, ts)`。
- 应用数据目录:`agent-sandbox/`(含我方托管 `opencode.json`,应用更新时覆写)。
- 备份 zip = progress + user_content + 设置,**不含任何密钥或 opencode 凭据**(后者我们本就不持有);恢复差异预览按 `(sentence_id, last_at)` 取新。
