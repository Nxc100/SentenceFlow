# 手动测试指引(alpha 自测用)

构建产物(`npx tauri build --bundles nsis` 之后):

| 产物 | 位置 | 用法 |
|---|---|---|
| 安装包 | `target/release/bundle/nsis/SentenceFlow_0.1.0_x64-setup.exe` | 双击安装(未签名,SmartScreen 会提示"仍要运行");含 content.db/channels.json 资源 |
| 便携目录 | `dist-portable/SentenceFlow/` | 免安装,直接双击 `SentenceFlow.exe`(content.db 已放在 exe 旁) |

学习数据写在 `%APPDATA%\app.sentenceflow.desktop\`(progress.db / user_content.db /
trial.json / license.sflic);想重置到"首启状态"删掉该目录即可
(试用锚点还有钥匙串副本:凭据管理器 → 普通凭据 → `sentenceflow`/`trial-anchor`)。

## 一、无 AI 通道也能测的(核心学习闭环)

1. **首启定级**:六张等级卡 + "帮我测一下"三问 → 直接进今日页,全程无通道配置。
2. **今日 → 开始练习**:L1/L2 每句先拆句重组(点词块,点错抖动)再整句打字。
3. **打字微交互**(§4.1/§6.2):
   - 严格模式错字不上屏:格子抖动 + 红字闪现;设置里关掉严格后错字上屏标红,Enter 校验;
   - 当前词为空时按空格应无动作(防双跳);词内有输入时空格跳词;
   - Backspace 跨词退格;↓ 显示答案(浅灰)/↑ 收起;
   - **中文输入法开着打字不应上屏任何汉字**(composition 拦截);
   - 答对瞬间 → 签名时刻:下划线消融 → 成分彩色卡聚拢 → 词性胶囊弹入 → 撒花 → 朗读(WebView 语音);任意按键跳终态。
4. **快捷键**:Ctrl 朗读、Ctrl+M 掌握(直入盒5)、Ctrl+Q 不熟悉(进错题本)、Shift+←→ 切题、Esc 暂停。
5. **SRS**:练完一轮后重进"今日",复习句应带小圆点标识;答错句当天可再练。
6. **内容库**:按场景筛选、点句展开解析(无撒花)、收藏 ☆、错题本"一键重练"、
   "我的句集"里用"中文\t英文"格式导入两句试试。
7. **报告**:今日卡/热力图/曲线/薄弱分析;"导出周报 PDF"走系统打印对话框选"另存为 PDF"。
8. **外观**:设置里切深色/护眼纸色/减少动效(减少动效开启后签名时刻应变为直接淡入、无撒花)。
9. **授权**:
   - 顶栏应显示"试用 · 剩 14 天";
   - 用 dev 私钥签一张测试许可证:
     `cargo run -p sf-license --features issuer -- issue --email test@example.com --major-max 3 --key-file tools/dev-keys/dev-signing-key.b64`
   - 把生成的 `.sflic` 文件内容粘进"设置 → 授权"→ 应见绿印章盖章动效;
   - 粘一段乱码 → 卡片抖动 + "签名无效"提示;
   - 把系统时间回拨一天再启动 → 试用应立即到期(体验模式,每日 5 句)。
10. **备份**:设置 → 数据 → 导出 zip;删数据目录后用"恢复"预览差异再确认。
11. **断网**:拔网线练习,一切学习功能应零降级;生成工坊显示引导态/离线提示。

## 二、需要 AI 通道的(有则测)

- 装了 **Ollama**(最省事):启动后设置 → AI 接入应自动绿点,选个模型 →
  生成工坊输入场景("机场值机")→ 句卡流式落下,✓ 入库 / ✕ 可展开原因;
  [停止] 保留已产出;中断任务出现 [续跑]。
- 装了 **opencode** 且已 `opencode auth login`:通道卡应三态引导正确;
  就绪后可点"微基准择优"(约 30 秒)。
- 有 **DeepSeek Key**:测试连接 → 绿勾;生成时 CostBar 显示预算与实时费用,
  预算调小(¥0.1)可测触顶优雅收尾。
- 解析页"问 AI"抽屉、报告页"AI 加练"预填、工坊页"本周 AI 点评"。

## 已知限制(测试时属预期,非 bug)

- 朗读用系统 TTS(piper 声音包未打入),音色一般;按键音/音效未打入。
- 图标是占位蓝方块;安装包未签名。
- 出厂句库目前 50 句(L1×20 / L2×20 / L3×10),L4–L6 空 —— 全量 5000 句
  待通道跑批;L4+ 等级练习会提示无句子。
- 生成句卡暂无单卡 [重新生成] 按钮(丢弃句可捞回)。
